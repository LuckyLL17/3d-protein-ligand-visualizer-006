# 3D 蛋白质结构与配体结合可视化平台

React + Vite + TypeScript + React Three Fiber 的结构生物学可视化基础项目，用于展示蛋白质骨架、关键残基、配体原子和结合口袋关系。

## 当前能力

- 卡通带状、表面模型、原子视图切换
- 关键残基选择与空间定位
- 配体原子点击选择
- 配体旋转
- 关键残基、配体原子和相互作用图例
- 结合口袋指标卡片
- 残基角色、空间坐标、距离和作用类型展示
- 分析会话导出/导入、本地草稿自动保存和刷新恢复
- 相互作用类型筛选与距离测量记录

## 分析会话

会话文件（JSON，当前格式版本 `2`）保存结构数据、显示模式、残基/原子选择、配体旋转角度、相互作用筛选条件和距离测量记录。页面状态变化后会写入浏览器本地草稿，刷新时自动尝试恢复；也可以手动导出为 `.json` 文件并在之后导入。

恢复前会完成完整校验：

- 版本 1 的旧会话会迁移到版本 2，并为新字段填充兼容默认值。
- JSON 损坏、字段缺失或类型错误会拒绝恢复。
- 高于当前版本或不兼容版本会拒绝恢复。
- 选中对象、相互作用、键或测量引用的残基/原子不存在会拒绝恢复。
- 恢复失败时保留当前工作区状态，不会用损坏数据覆盖可用状态。

## 启动

```bash
npm install
npm run dev
```

当前使用内置示例结构数据，后续可接入 PDB/mmCIF 文件解析、真实原子键推断、分子对接结果、氢键几何筛选和结构比对。
